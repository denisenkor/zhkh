# ЖКХ Крым для Home Assistant

Интеграция для получения балансов и задолженности по коммунальным услугам из личных кабинетов поставщиков.

## Установка через HACS

1. Откройте HACS → Интеграции.
2. В меню справа сверху выберите **Пользовательские репозитории**.
3. Добавьте `https://github.com/denisenkor/zhkh` с категорией **Integration**.
4. Найдите «ЖКХ Крым» и установите.
5. Перезапустите Home Assistant.
6. Откройте Настройки → Устройства и службы → Добавить интеграцию → «ЖКХ Крым».

## Поддерживаемые поставщики

- ГУП РК «Крымтеплокоммунэнерго» — [личный кабинет](https://lk.tce.crimea.ru/cabinet/).
- Крымэнерго — [личный кабинет](https://lk.crimea-energy.ru/).
- Крымгазсети — [личный кабинет](https://lkk.crimeagasnet.ru/).
- Крымэкоресурсы — [личный кабинет](https://lk.crimea-ecor.ru/index.htm).
- НО «РФ КРМД РК» — [официальный сайт](http://kaprem82.ru/) · [личный кабинет](https://lk091.eisgkh.ru/index.htm).

Для Крымэнерго и Крымгазсети одна авторизация может возвращать несколько лицевых счетов. Для Крымэкоресурсы и НО «РФ КРМД РК» подключается отдельный лицевой счёт. Каждый счёт отображается отдельным устройством. Для Крымгазсети создаются ровно два сенсора — поставщик и задолженность; для каждого устройства доступна своя кнопка ручного обновления.

## Сущности

Для Крымэкоресурсы создаются ровно две сущности на устройстве:

- **Поставщик** — название поставщика из таблицы услуг.
- **Задолженность** — значение из столбца «Тариф» в рублях.
- **Обновить данные** — кнопка ручного обновления.


Для Крымгазсети на каждом устройстве создаются ровно две сущности:

- **Поставщик** — название управления.
- **Задолженность** — сумма в рублях: положительное значение означает долг, отрицательное — аванс.
- **Обновить данные** — кнопка ручного обновления на устройстве.

Для НО «РФ КРМД РК» создаются две сущности: «Поставщик» и «Задолженность». Задолженность берётся из итоговой суммы платежа на странице оплаты, включая начисления и пеню.

Наборы сущностей уже существующих коннекторов Крымтеплокоммунэнерго и Крымэнерго не изменяются.

## Расписание обновления

Число месяца настраивается отдельно для каждого подключения в параметрах интеграции. Плановое обновление выполняется в 06:00 по часовому поясу Home Assistant.

Если в месяце нет выбранного числа, обновление выполняется в последний день месяца. Если Home Assistant выключен в запланированное время, пропущенное обновление не выполняется; запуск Home Assistant сам по себе не запускает запрос.

При временных сетевых ошибках интеграция автоматически повторяет запрос до трёх раз с интервалом 10 секунд.

## Безопасность

Не публикуйте HAR-файлы, cookies, токены или пароль от личного кабинета. Пароль вводится только в форме настройки Home Assistant. Сессионные данные Крымгазсети хранятся в памяти интеграции и не записываются в журналы.
