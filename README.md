# ЖКХ для Home Assistant

Интеграция для получения балансов и задолженности по коммунальным услугам из личных кабинетов поставщиков.

## Установка через HACS

1. Откройте HACS → Интеграции.
2. В меню справа сверху выберите **Пользовательские репозитории**.
3. Добавьте `https://github.com/denisenkor/zhkh` с категорией **Integration**.
4. Найдите «ЖКХ» и установите.
5. Перезапустите Home Assistant.
6. Откройте Настройки → Устройства и службы → Добавить интеграцию → «ЖКХ».

## Поддерживаемые поставщики

- ГУП РК «Крымтеплокоммунэнерго» — [личный кабинет](https://lk.tce.crimea.ru/cabinet/).
- Крымэнерго — [личный кабинет](https://lk.crimea-energy.ru/).

Для Крымэнерго одна авторизация может возвращать несколько лицевых счетов. Каждый счёт отображается отдельным устройством со своими сенсорами поставщика, номера лицевого счёта, баланса и времени последней синхронизации.

## Сущности

Для каждого подключения создаются:

- **Поставщик** — название организации или подразделения.
- **Задолженность / Баланс** — сумма в рублях. Для Крымэнерго отображается знак и значение, возвращённые API поставщика.
- **Последнее обновление** — дата и время последнего успешного получения данных.
- **Обновить данные** — кнопка ручного обновления.

## Расписание обновления

Число месяца настраивается отдельно для каждого подключения в параметрах интеграции. Плановое обновление выполняется в 06:00 по часовому поясу Home Assistant.

Если в месяце нет выбранного числа, обновление выполняется в последний день месяца. Если Home Assistant выключен в запланированное время, пропущенное обновление не выполняется; запуск Home Assistant сам по себе не запускает запрос.

При временных сетевых ошибках интеграция автоматически повторяет запрос до трёх раз с интервалом 10 секунд.

## Безопасность

Не публикуйте HAR-файлы, cookies, токены или пароль от личного кабинета. Пароль вводится только в форме настройки Home Assistant. Токен API используется только в памяти интеграции и не записывается в журналы.
