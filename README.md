# ЖКХ для Home Assistant

Интеграция для чтения задолженности по коммунальным услугам из личных кабинетов поставщиков.

## Установка через HACS

1. Откройте HACS → Интеграции.
2. В меню справа сверху выберите **Пользовательские репозитории**.
3. Добавьте `https://github.com/denisenkor/zhkh` с категорией **Integration**.
4. Найдите «ЖКХ» и установите.
5. Перезапустите Home Assistant.
6. Откройте Настройки → Устройства и службы → Добавить интеграцию → «ЖКХ».

## Поддерживаемые поставщики

- ГУП РК «Крымтеплокоммунэнерго» — личный кабинет [lk.tce.crimea.ru](https://lk.tce.crimea.ru/cabinet/).

## Сущности

Для каждого добавленного подключения создаются ровно два сенсора:
- поставщик;
- задолженность (RUB).

Обновление данных — каждые 30 минут.

## Важно

Интеграция пока находится в тестовой разработке. Авторизация и разбор ответа должны быть проверены на реальном аккаунте. Не публикуйте HAR-файлы, cookies, токены или пароль. Вводите пароль только в форме Home Assistant.

## Разработка

Исходный код находится в `custom_components/zhkh`. Ошибки и предложения можно оставлять в Issues.
